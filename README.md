# StorageSP

Клиентский Fabric-мод для Minecraft 1.21.11: подсвечивает хранилища
(сундуки, бочки, шалкеры и любые блоки из конфига) через стены —
боксы и/или линии-трейсеры, с настраиваемым списком блоков и меню.

**Только клиент.** Ставится в `.minecraft/mods` только у вас, серверу
ничего дополнительно не нужно — мод читает уже загруженные клиентом чанки
(та же информация, что обычно передаётся вам сервером в ходе игры).

## Сборка

Нужен установленный JDK 21.

```bash
./gradlew build
```

Готовый `.jar` появится в `build/libs/storagesp-1.0.0.jar`.
Скопируйте его в папку `mods` рядом с Fabric API того же диапазона версий.

Перед сборкой сверьте версии `yarn_mappings`, `loader_version` и
`fabric_version` в `gradle.properties` с актуальными на
https://fabricmc.net/develop — Fabric часто выпускает новые билды под
патч-версии вроде 1.21.11, и я не могу гарантировать, что зафиксированные
здесь номера будут последними на момент вашей сборки.

## Требования

- Minecraft 1.21.11
- Fabric Loader ≥ 0.16.10
- Fabric API (версия под 1.21.11)
- Java 21

## Управление

- **Controls → StorageSP** — назначьте клавиши для:
  - `Вкл/Выкл ESP` — быстрый общий тумблер
  - `Открыть меню` — открывает GUI настроек
- В меню:
  - Общий переключатель показа хранилищ
  - Отдельно переключаются боксы и линии-трейсеры
  - Переключатель "сквозь стены" (если выключить — хранилища видно только в прямой видимости, как подсказка/подсветка, а не x-ray)
  - Слайдер радиуса сканирования (в чанках)
  - Список блоков с индивидуальным вкл/выкл и добавлением своих ID
    (например `minecraft:decorated_pot`, блоки других модов и т.д.)

## Конфиг

Файл `config/storagesp.json` создаётся при первом запуске. Можно редактировать
вручную — формат:

```json
{
  "masterEnabled": true,
  "renderBoxes": true,
  "renderTracers": true,
  "renderThroughWalls": true,
  "scanRadiusChunks": 6,
  "trackedBlocks": [
    { "blockId": "minecraft:chest", "enabled": true, "colorR": 1.0, "colorG": 0.85, "colorB": 0.2, "category": "containers" }
  ]
}
```

Маска `minecraft:*_shulker_box` покрывает все цветные варианты шалкеров одной записью.

## Важно

Этот мод даёт заметное игровое преимущество (аналог x-ray, только для
контейнеров). Используйте его в соответствии с правилами **вашего** сервера.
Установка такого мода без разрешения администрации на чужом сервере обычно
нарушает правила большинства проектов и может привести к бану — это
ответственность того, кто устанавливает мод.
